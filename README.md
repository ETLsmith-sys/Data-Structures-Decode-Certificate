# Data Structures Decode

**Certificate of Completion** — Cloud Native Base Camp (~2024)

This repository documents my completion of *Data Structures Decode*, an
implementation-first course covering core data structures from the ground
up. Completed during my backend development foundation, prior to
transitioning into Data Engineering.

## 📜 Certificate
See [`certificate.pdf`](./certificate.pdf) for the official certificate.

## 📚 Topics Covered

- **Memory & Data Types** — how data is represented and stored in memory
- **Arrays** — introduction and core operations
- **Linked Lists** — singly and doubly linked list implementations
  (including a JavaScript implementation)
- **Array vs. Linked List** — time-complexity comparison
- **Stacks** — array-based and linked-list-based implementations
- **Queues** — linked-list-based implementation
- **Key-Value Pairs / Dictionaries** — implementation from scratch
- **Hashing** — introduction and FNV-1a hash function implementation
- **Hash Tables** — introduction and full implementation
- **Trees**
  - Binary Trees — implementation
  - Binary Search Trees — insert, find, delete, and self-balancing
  - Heaps — implementation
  - Priority Queues
